# 🌽 Maize Maze — 3D First-Person Corn Maze Game

[![Unity](https://img.shields.io/badge/Engine-Unity-black?style=flat&logo=unity)](https://unity.com/)
[![Language](https://img.shields.io/badge/Language-C%23-blue?style=flat&logo=csharp)](https://learn.microsoft.com/en-us/dotnet/csharp)
[![Genre](https://img.shields.io/badge/Genre-First--Person%20Maze-green)](#)
[![Platform](https://img.shields.io/badge/Platform-PC-brightgreen?style=flat&logo=windows)](#)

**Maize Maze** is a procedural 3D first-person maze game developed in Unity using C#. Explore a cornfield labyrinth, collect corn cobs and bonus coins, avoid farm hazards, and reach the exit before time or lives run out.

The game builds its environment and gameplay objects at runtime, so a playable level can be created without manually placing maze walls, pickups, or enemies in a scene.

## 🎮 Game Objective

1. Enter the maze and explore its corridors.
2. Collect the required corn cobs to unlock the exit gate.
3. Collect coins to increase your score.
4. Avoid traps, farm dogs, and crows that can cost lives and points.
5. Reach the exit before the countdown expires.
6. Complete increasingly challenging mazes and continue progressing.

---

## ✨ Features

- **Procedural Maze Generation:** Maze corridors are generated at runtime using a randomized maze-building algorithm.
- **Three Difficulty Modes:**
  - **Easy:** Smaller maze, fewer hazards, minimap and exit beacon.
  - **Medium:** Larger maze, more enemies and traps, tighter time limit.
  - **Hard:** Complex maze with more threats and no minimap or beacon.
- **Progressive Levels:** After Hard mode, additional levels generate larger mazes and add hazards.
- **Collectibles:**
  - 🌽 Corn cobs count toward unlocking the exit gate.
  - 🪙 Coins provide bonus score.
- **Hazards:**
  - 🐕 Farm dogs patrol and chase the player.
  - 🐦 Crows swoop toward the player.
  - ⚠️ Traps damage the player.
- **Countdown Timer:** Creates pressure to complete the maze quickly.
- **Lives and Scoring:** Hazards reduce lives and score; completing a level rewards remaining time.
- **First-Person Controls:** Character movement, mouse look, and sprinting.
- **Pause Menu:** Resume, restart the maze, return to the main menu, or quit.
- **HUD:** Displays timer, lives, collected cobs, score, level, and objective messages.
- **Minimap and Beacon:** Available in Easy and Medium modes to help navigation.
- **Runtime Audio:** Pickup, damage, gate, win, and lose sounds are generated by the game.

## 🧩 Gameplay and Progression

| Mode | Maze | Navigation | Challenge |
|---|---|---|---|
| Easy | Small | Minimap + beacon | Fewer hazards |
| Medium | Medium | Minimap + beacon | More hazards and shorter timer |
| Hard | Large | No minimap or beacon | More difficult navigation |
| Extra levels | Increasing size | Depends on difficulty settings | Additional enemies and traps |

### Collectibles and scoring

- Collect the required number of corn cobs to open the exit gate.
- Collect coins for bonus points.
- Taking damage costs a life and reduces score.
- Escaping adds a time-based bonus to the score.

### Win and lose conditions

- **Win:** Unlock the gate and reach the exit.
- **Lose:** Run out of lives or allow the timer to expire.

## 🚀 Getting Started

### Prerequisites

- Unity Editor (Unity 2020.3 or later recommended)
- Unity Hub
- Visual Studio or Visual Studio Code (optional, for editing C#)

### Setup

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repository>.git
   ```
2. Open **Unity Hub**.
3. Add the cloned project folder using **Add project from disk**.
4. Open the project in Unity and allow scripts to compile.
5. Open a scene, or create an empty scene if needed.
6. Press **Play**. The `MaizeMazeGame` script automatically creates the game at runtime.

### Script-only setup

If this repository contains the standalone `MaizeMazeGame.cs` script rather than a complete Unity project:

1. Create or open a Unity project.
2. Copy `MaizeMazeGame.cs` into the project's `Assets` folder.
3. Open any scene.
4. Press **Play** to launch the automatically initialized game.
